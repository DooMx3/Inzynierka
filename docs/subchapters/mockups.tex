\subsection{Graphical user interface design}
The design of an application's interface is crucial, as it directly impacts the user experience. The goal is to ensure both ease of use and clarity of the individual interface elements. Instead of listing the mockups only as a range of figure numbers, each screen is described next to the corresponding image. The views follow the same role structure as the requirements: guest, logged-in user, vineyard worker, oenologist and vineyard owner. Recurring layout elements---the top bar, the search field and the profile menu---are shared across authenticated screens so that moving between modules remains consistent.
