\subsection{Use Cases}
Use case diagrams were developed to clearly define the system’s boundaries and the roles played by individual users within it. The system has been divided into main roles (actors), reflecting the actual staffing structure at the vineyard and winery \cite{armour2000advanced}. Each diagram lists the operations available to a given actor. The vineyard worker and the vineyard owner are shown in Figure~\ref{fig:usecase_worker} and Figure~\ref{fig:usecase_owner}. The remaining roles---oenologist, guest and logged-in user---are shown in Figure~\ref{fig:usecase_oenologist}, Figure~\ref{fig:usecase_guest} and Figure~\ref{fig:usecase_logged}.

The vineyard worker diagram covers day-to-day field work: tasks, spraying, plant diseases and harvest records, each with view, add, edit and delete operations. The vineyard owner diagram extends that set with organisation, staff, fields, substances, equipment, offerings, reports and QR codes.

Because this actor has the largest number of use cases, the diagram occupies a page of its own.
